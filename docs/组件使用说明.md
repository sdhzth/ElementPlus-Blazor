### ElButtonGroup

按钮组

**参数**

| 参数名 | 类型 | 说明 |
|--------|------|------|
| ``ChildContent`` | ``RenderFragment`` | |
| ``Size`` | ``ButtonSize`` | |

> 💡 **组内单颗按钮「可点击 / 隐藏」怎么控制**：`ElButtonGroup` 自己只管把子按钮粘成一段圆角连体，
> 并向下级联 `Size` / `Type` / `Disabled`，**没有**逐颗的可见性开关。
> 不可点击用子按钮的 `Disabled`（或在组上写 `Disabled` 一次管全组）；
> 不出现用子按钮的 `Visible="false"`（批次㊷新增，见上方 ElButton 参数表）。
> 两者语义不同：`Disabled` 保留 DOM 与占位，`Visible=false` 整棵子树不进渲染树。
> 详见 `docs/button-visible-and-select-multi-label.md`。

**示例**

```razor
<ElButtonGroup>
```

## 表单组件

### ElInput

文本输入框，支持单行、多行（Textarea）、密码、字数限制、前后缀图标、可清除按钮等。既可单独使用，也可配合 **ElForm + ElFormItem** 实现级联绑定与校验。

> 💡 **双向绑定说明**：使用 @bind-Value="变量" 即可实现标准 Blazor 双向绑定（内部调用 ValueChanged），无需配合 ElFormItem。当放入 ElFormItem 内部时，会自动通过级联参数绑定到 Form 的 Model。

**参数**

| 参数名 | 类型 | 说明 |
|--------|------|------|
| Value | TValue | 当前值，配合 ValueChanged 或 @bind-Value 使用 |
| ValueChanged | EventCallback<TValue> | 值改变回调（@bind-Value 就是它的语法糖） |
| Type | InputType | 输入框类型：Text / Password / Textarea |
| Placeholder | string | 占位提示文本 |
| Size | InputSize | 尺寸：Normal / Large / Small |
| Disabled | bool | 是否禁用 |
| Readonly | bool | 是否只读 |
| Clearable | bool | 是否显示清除按钮 |
| EnableClearButton | bool | 手动控制清除按钮显示（与 Clearable 配合） |
| EnableClearButtonChanged | EventCallback<bool> | EnableClearButton 改变时回调 |
| ShowPassword | bool | 密码模式下显示眼睛图标 |
| MaskedPassword | bool | 批次86 引入、批次87 返工：密码框改走 CSS 掩码，**出生即 `type=text`** + 内联 `-webkit-text-security: disc`（Chrome 的密码分类在元素入树时刻定型，出生干净才有用），掩码档不再发 `autocomplete="new-password"`，Chrome 的「保存密码」分析与离开路径的挂锁图标都不再命中这一格；不支持该属性的浏览器同步探测后出生即原生 `password`，绝不明文，默认 `false`。详见 `docs/input-alignment.md` §二 |
| Maxlength | object | 最大字符数 |
| Minlength | object | 最小字符数 |
| ShowWordLimit | bool | 配合 Maxlength 显示字数统计（如 12/50） |
| Rows | int | Textarea 行数 |
| Resize | string | Textarea resize 样式（both / horizontal / vertical / none） |
| PrefixIcon | string | 前缀图标 class（如 el-icon-user） |
| SuffixIcon | string | 后缀图标 class |
| Prefix | RenderFragment | 自定义前缀插槽 |
| Suffix | RenderFragment | 自定义后缀插槽 |
| Image | string | 输入框背景图 URL |
| InputStyle | string | 内层 input 的自定义样式 |
| Autocomplete | string | HTML autocomplete 属性，默认 "off" |
| Autofocus | bool | 是否自动聚焦 |
| Id | string | 自定义 DOM id（默认自动生成 el-input-xxx） |
| ValidateEvent | bool | 失焦时是否触发校验，默认 	rue |
| OnFocus | EventCallback<FocusEventArgs> | 获得焦点回调 |
| OnBlur | EventCallback<FocusEventArgs> | 失去焦点回调 |
| OnInput | EventCallback<TValue> | 每次按键输入回调 |
| OnChange | EventCallback<TValue> | 值改变并提交（blur / Enter）时回调 |
| OnClear | EventCallback<MouseEventArgs> | 点击清除按钮回调 |
| OnKeyDown | EventCallback<KeyboardEventArgs> | 键盘按键回调 |
| OnPrefixIconClick / OnSuffixIconClick | EventCallback<MouseEventArgs> | 前后缀图标点击回调 |
| Formatter / Parser | Func<TValue, string> / Func<string, string> | 值格式化 / 解析函数（自定义类型场景） |

**示例 1：基础双向绑定（单独使用）**

`azor
<ElInput TValue="string" @bind-Value="userName" Placeholder="请输入用户名" />

@code {
    private string userName = "";
}
`

**示例 2：手动 Value / ValueChanged 回调**

`azor
<ElInput TValue="string"
         Value="@keyword"
         ValueChanged="@(v => { keyword = v; DoSearch(); })"
         Placeholder="搜索关键词…" />

@code {
    private string keyword = "";
    private void DoSearch() { /* 搜索逻辑 */ }
}
`

**示例 3：配合 ElForm / ElFormItem 的级联绑定 + 校验**

`azor

    <ElFormItem>

    </ElFormItem>

@code {

    class LoginForm

        public string UserName { get; set; } = "";
        public string Password { get; set; } = "";
    }
}
`

**示例 8：OnInput / OnChange 事件 + EnableClearButton**

`azor
<ElInput TValue="string"
         @bind-Value="liveText"
         Clearable="true"
         OnInput="@OnEachKeystroke"
         OnChange="@OnCommit"
         EnableClearButton="@showClear"
         EnableClearButtonChanged="@(v => showClear = v)"
         Placeholder="每次按键都会触发 OnInput…" />

<p>已输入 @liveText.Length 个字符（oninput）</p>
<p>最近提交：@committed（onchange）</p>

@code {
    private string liveText = "";
    private string committed = "";
    private bool showClear;

    private void OnEachKeystroke(TValue val)
    {
        // 每次按键都触发，适合实时搜索
    }

    private void OnCommit(TValue val)
    {
        committed = Convert.ToString(val);
        // blur 或 Enter 时触发，适合最终提交
    }
}
`

> 上面这种「预置 `Value` ＋ 声明式 `ElOption` 子项」的写法，首屏就会回显「北京」。
> 本库的下拉弹层是**首次点开才挂载**的（与官方的 `v-show` 不同），所以候选项首屏并不在 `Options` 里；
> 组件会把 `ChildContent` 的渲染帧只读扫一遍来补这段空窗，**不会**提前建弹层 DOM。
> 值不在候选项里时触发区留空（不显示裸值）。口径与验证见 `docs/select-alignment.md`。
>
> 💡 **多选（`Multiple="true"`）同样吃这个空窗，批次㊷起一起补上**：数字字典（`TValue` 是 `int`、
> `Text` 是汉字）的预置值此前会在胶囊里显示成 `0 × 1 × 2 ×`，点开一次下拉才变回汉字——
> 因为拿不到选项文本时只能回落 `Convert.ToString(value)`。现在取值优先级是
> **已注册选项 → `Options`/`dict` 数据源 → 只读扫描 `ChildContent` → 原始值字符串**，
> 首屏即显示汉字。三条边界：① 点开过下拉后一律以真注册的选项为准，扫描只是首屏那一帧的补位；
> ② 只认声明式 `ElOption` 子项，`ElSelectV2` / `ElSelectTreeGrow` 那种非 `ElOption` 结构的仍回落到原始值，
> 嵌套超过 4 层的候选项同样扫不到（是回落，不是崩）；③ 未知值**逐值**回落，不会因为集合里有一个不认识就整组退回裸值。
> 口径与验证见 `docs/button-visible-and-select-multi-label.md`。

> 推导、800×700 视口的逐列实测与翻面变异读数记在 `docs/table-header-cell-and-column-width.md` §2；
> auto 档的完整来龙去脉（含「305/305/381/114」那组改前复现与四档消费侧写法的实测）在 `docs/table-auto-column-width.md`。
