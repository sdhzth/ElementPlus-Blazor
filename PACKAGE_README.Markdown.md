# Element-Plus.Markdown

Element-Plus.Markdown provides Markdown editor components for Element-Plus.

## Install

```powershell
dotnet add package Element-Plus.Markdown --prerelease
```

## Requirements

Install and configure the main Element-Plus package first:

```powershell
dotnet add package Element-Plus --prerelease
```

Then load the Markdown static assets required by your host application.
